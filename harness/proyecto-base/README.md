# Andes Logística — app interna

React 19 + TypeScript + Vite + Tailwind CSS v4. Alias `@/` apunta a `src/`.

- Código en `src/` (punto de entrada: `src/App.tsx`).
- Datos de ejemplo en `src/data/`.
- `npm run build` compila y revisa tipos; `npm run preview -- --port <puerto>` sirve el build.

Andes Logística no tiene design system propio.
